# 拾途 · 旅程回忆

自由地图定点，为不同地点收藏照片、日期、心情和旅途故事。支持时间线回看、编辑、JSON 备份导入与导出。

## 使用

GitHub Pages 从 main 分支根目录发布，无需构建。也可用任意静态 HTTP 服务器运行本目录。

真实记录和上传照片保存在当前浏览器的 IndexedDB 中，不上传到仓库，也不会自动跨设备同步。迁移网址或清理浏览器前，请先导出备份，再到新网址导入。

地图底图使用 OpenStreetMap，搜索使用 Nominatim（部分城市可离线匹配）。地图与在线搜索需要网络。示例照片来自 Unsplash，仅作氛围示意，不代表对应地点实拍。地图库为 Leaflet 1.9.4。
