# 拾途 · 旅程回忆

自由地图定点，为不同地点收藏照片、日期、心情和旅途故事。支持时间线回看、编辑、JSON 备份导入与导出。

## 使用

GitHub Pages 从 main 分支根目录发布，无需构建。也可用任意静态 HTTP 服务器运行本目录。

真实记录和上传照片保存在当前浏览器的 IndexedDB 中，不上传到仓库，也不会自动跨设备同步。迁移网址或清理浏览器前，请先导出备份，再到新网址导入。

地图底图使用 Esri World Topographic Map（地图角落提供来源署名），搜索使用 Nominatim（部分城市可离线匹配）。地图与在线搜索需要网络。示例照片来自 Unsplash，仅作氛围示意，不代表对应地点实拍。地图库为 Leaflet 1.9.4。

## 15 个旅程地点

已加入都江堰、四姑娘山、达瓦更扎、九寨沟、广元、重庆、南充、西安、峨眉山、大理、昆明、香格里拉、深圳、西岭雪山、自贡。每处提供可编辑回忆文案草稿；日期留空，插画封面可由用户照片替换。坐标为城市或景区参考点，可在编辑时调整。

新增草稿通过 IndexedDB 的独立迁移标记，仅在每个浏览器首次升级时加入一次。已有记录保留；删除的草稿不会在刷新后重新出现。未填写日期的记录显示“日期待补充”，不连入按时间排序的地图线。旧版备份仍可导入。

都江堰条目已按用户提供的内容更新为 2023-05-27，包含完整分段原文与 5 张旅行照片。独立的一次性更新同时适用于已保存旧草稿的浏览器；后续本机编辑不会在刷新时被重置。导出备份会将内置照片转换为完整图片数据，便于迁移。

西岭雪山条目已加入 6 张旅行照片（assets/xiling-20221228/，已压缩并去除 EXIF）。独立的一次性迁移只会给已保存的记录补充这些照片，不覆盖本机已有的文案和照片，也不会让已删除的记录重新出现。
